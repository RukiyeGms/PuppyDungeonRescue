Puppy Dungeon Rescue 

Puppy Dungeon Rescue is a 2D platformer and dungeon-crawler prototype developed in Unity. Play as Puppy, a rescue adventurer who enters a dangerous dungeon to save a trapped Sheep and bring them back to safety.
Gameplay
Explore interconnected rooms, overcome platforming challenges, avoid spikes, fight enemies, and collect coins. Find the key, free Sheep from the cage, and return to the dungeon entrance to complete the rescue.

The dungeon contains five connected rooms, with challenges introduced gradually:
1. Introduction: Learn basic movement, jumping, attacking, and interacting with the environment.
2. Movement challenges: Practice double jumps, wall sliding, and wall jumping while avoiding spikes.
3. Platforming and combat: Navigate vertical passages and platforms while dealing with patrolling enemies.
4. Advanced traversal: Combine movement skills, combat, and careful timing to cross hazardous areas.
5. Rescue objective: Reach Sheep's cage, complete the rescue, and make your way back to the exit.

Features
- 2D platforming with double jump, wall slide, and wall jump mechanics
- Melee combat and patrolling enemies
- Interconnected rooms with door transitions
- Hazards, collectibles, and interactable objects
- A rescue objective with a clear end goal
- Pause menu and separate music and sound-effect volume controls

Controls
Action	Key
Move	Left / Right Arrow
Jump / Double Jump	Up Arrow
Attack	X
Interact	A
Pause	Tab


Built With
- Engine: Unity 6.3 LTS (6000.3.23f1)
- Language: C#
- Platform: Windows
Project Status
This is a playable prototype developed as part of a game development bootcamp. It focuses on a compact rescue mission rather than a full-length game.
