# Puppy Dungeon Rescue

![Puppy Dungeon Rescue — Story and Rescue](Screenshots/screenshot_1.jpg)

**Puppy Dungeon Rescue** is a 2D platformer and dungeon-crawler prototype made with Unity. Play as Puppy, a rescue adventurer who enters a dangerous dungeon to save a trapped Sheep and bring them back to safety.

**[Play / Download on itch.io](https://rkistrin.itch.io/puppy-dungeon-rescue)**

## Gameplay

Explore five interconnected dungeon rooms, fight enemies, navigate spikes and platforming challenges, and find a key to free Sheep from a cage. Carry Sheep in Puppy's bag and return to the dungeon entrance to complete the rescue.

The challenges increase as you progress through the rooms:

1. **Introduction:** Learn basic movement, jumping, attacking, and interactions.
2. **Movement challenges:** Practice double jumping, wall sliding, and wall jumping while avoiding spikes.
3. **Platforming and combat:** Navigate vertical passages and platforms while dealing with patrolling enemies.
4. **Advanced traversal:** Combine movement skills, combat, and careful timing in more hazardous areas.
5. **Rescue objective:** Find the key, rescue Sheep, and return safely to the entrance.

## Features

- 2D movement with double jump, wall slide, and wall jump mechanics
- Melee combat against patrolling enemies
- Five interconnected rooms with door transitions
- Spike hazards and platforming challenges
- Coins dropped by defeated enemies or obtained from treasure chests
- A complete rescue mission with a clear ending
- Pause menu and separate music and sound-effect volume controls

## Controls

| Action | Key |
| --- | --- |
| Move left / right | Left / Right Arrow |
| Jump / Double Jump | Up Arrow |
| Attack | X |
| Interact | A |
| Pause | Tab |

### Movement Tips

- **Double Jump:** Press Jump again while airborne.
- **Wall Slide:** While airborne, keep moving toward the lighter-colored wall sections.
- **Wall Jump:** Press Jump while wall sliding to jump away from the wall.

## Play the Game

Download the **Windows build** from [itch.io](https://rkistrin.itch.io/puppy-dungeon-rescue), extract the ZIP, and run `PuppyDungeonRescue.exe`.
